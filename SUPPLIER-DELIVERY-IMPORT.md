# Приёмка поставки по накладной

В админке откройте «Приёмка», загрузите PDF накладной и, если есть, чек или подтверждение оплаты в PDF, PNG либо JPEG. Система разбирает товары, фасовки, суммы и налоги, сопоставляет артикулы поставщика с SKU сайта и показывает предварительную проверку. Непонятное соответствие можно выбрать вручную; выбор сохраняется для следующих поставок.

По каждой строке укажите исключения из продаваемого остатка: подарочные и личные единицы. Обычные строки сразу предложены целиком на продажу. После проверки одна кнопка сохраняет частные файлы, закупочные предложения, распределение и движения склада в одной транзакции. Розничная цена при этом не меняется.

Одинаковый PDF или номер накладной не увеличит остаток повторно. Для Albet `VMW 64286` код также учитывает приёмку, уже внесённую вручную. Подарочный Churu и личный Leonardo следует распределить в предварительном просмотре; назначение товара нельзя узнать из накладной. Чек сохраняется отдельно. Совпадение суммы в его PDF не означает автоматического подтверждения оплаты.

Автоматический разбор сейчас поддерживает формат накладной Albet. Неизвестный формат останавливается до записи склада. Для других поставщиков можно добавить отдельные парсеры, сохранив общую проверку, сопоставление SKU и учёт остатков.
