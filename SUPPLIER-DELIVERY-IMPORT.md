# Приёмка поставки по накладной

В админке откройте «Приёмка», загрузите PDF накладной и, если есть, чек или подтверждение оплаты в PDF, PNG либо JPEG. Система разбирает товары, фасовки, суммы и налоги, сопоставляет артикулы поставщика с SKU сайта и показывает предварительную проверку. Непонятное соответствие можно выбрать вручную; выбор сохраняется для следующих поставок.

После проверки вся накладная поступает на физический склад одной операцией. Код сохраняет частные файлы, закупочные предложения и движения склада в одной транзакции. Розничная цена при этом не меняется. Решение о дальнейшем использовании товара не требуется при приёмке.

В этом же разделе есть отдельное действие «Списать со склада»: выбрать SKU, количество и причину «Маркетинг и подарки» либо «Личное потребление». Оно уменьшает только свободный физический остаток, фиксирует сотрудника, время, причину и сохранённую закупочную стоимость. Зарезервированный для клиента товар списать нельзя. Это внутренний складской расход; бухгалтерскую проводку система не создаёт.

Если нужно списать отдельные тюбики из смешанного короба Churu, сначала нажмите «Разобрать 1 короб Churu на тюбики». Существующий механизм фасовки перенесёт остаток из SKU короба в SKU отдельных тюбиков; затем каждый тюбик можно списать по нужной причине.

Одинаковый PDF или номер накладной не увеличит остаток повторно. Для Albet `VMW 64286` код также учитывает приёмку, уже внесённую вручную. Чек сохраняется отдельно. Совпадение суммы в его PDF не означает автоматического подтверждения оплаты.

Автоматический разбор сейчас поддерживает формат накладной Albet. Неизвестный формат останавливается до записи склада. Для других поставщиков можно добавить отдельные парсеры, сохранив общую проверку, сопоставление SKU и учёт остатков.
